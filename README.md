Z-CITY DESC!
Что добавляет этот аддон:
Проработанную систему здоровья и медицины. Стандартное здоровье из HL2 теперь никак не используется. С текущей системой персонаж умирает только тогда, когда умирает его мозг. Мозг может умереть либо от прямого урона, либо от недостатка кислорода, что в свою очередь может произойти по множеству разных причин. Так же имеются разные крутые эффекты при различных обстоятельствах, например при смерти от потери крови
